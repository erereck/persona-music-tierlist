# Persona Music Archive — Tier List

Editor de tier list dedicado às 887 faixas mainline de Persona 1–5.

## Recursos

- dez categorias iniciais personalizáveis;
- drag-and-drop e seleção em massa;
- filtros por família e por edição;
- busca por título exibido, título original e jogo;
- atalhos 1–0, desfazer/refazer e salvamento automático local;
- exportação em PNG e backup/importação em JSON;
- 887 capas WebP carregadas sob demanda;
- layout responsivo para desktop e celular.

## Desenvolvimento

```bash
npm install
npm run dev:pages
```

## Build do GitHub Pages

```bash
npm run build:pages
```

O workflow em `.github/workflows/deploy-pages.yml` publica automaticamente a branch `main`.
